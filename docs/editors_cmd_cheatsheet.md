
# If you are using VI or VIM

You will need to access the command line of the editor to be able to perform some actions.
Once you enter your editor, either by calling it 'vi file.md' or by using 'git commit' without -m, you will see the file but you are interacting with the one liner terminal of the editor. 

1. To start editing press `i` in your keyboard.

`i` = insert

2. If you are finished and want to save (write) and quit:

`esc` = to access the editor terminal, you can see in the botton of the page once you start writing

':wq' **+ enter** = ':' execute 'w' save writing and 'q' quit

3. If you want to save without leaving the file

'esc' = to access the editor terminal

':w' **+ enter** = ':' execute 'w' save writing

4. If you want to leave the file without saving

'esc': access terminal

':q' : ':' execute 'q' quit

or

':q!' to force quiting without saving

Find more about the editors use [here](http://www.linux-admins.net/2011/01/vi-cheat-sheet.html)

# If you are using Nano


Once you enter your editor, either by calling it 'nano file.md' or by using 'git commit' without -m, you will see the file and you can imediately start writing in Nano.


1. If you are finished and want to save (write) and quit:

'ctrl + X' : to exit nano.

If there are unsaved changes nano will ask if you want to save them, you answer yes by typing 'S' and pressing **enter**. 

It will ask if you want to change the file name, by pressing **enter** you keep the same name.

3. If you want to save without leaving the file

'ctrl + O' :  Will save the current changes

4. If you want to leave the file without saving

'ctrl + X' : to exit nano, If there are unsaved changes.

If there are no changes, you will exit the file.

If you have changes and don't want to save them, you answer no by typing 'N' and pressing **enter**. 


Find more about the editors use [here](https://gist.github.com/jobayer977/81efce930dee0037079a51ccace0b892)
